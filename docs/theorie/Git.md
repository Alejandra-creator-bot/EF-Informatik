## Warum Git?

**Versionsverwaltung:** 

Git speichert jede wichtige Änderung und ermöglicht es:
- Ältere Versionen wiederherzustellen
- Änderungen zu verfolgen
- Gemeinsam an Projekten zu arbeiten

**Wichtige Begriffe:**

*Repository*

- Ein Projektordner
- verfolgt darin alle Änderungen an den Dateien.

*Lokal und Remote:*

- Lokales Repository:
Projekt auf meinem Computer.

- Remote Repository:
Projekt auf einem Server.


*Clone:*  
Copie von einem Repository
- kopiert die aktuellen Dateien
- kopiert alle alten Versionen
- kopiert alle Commits
- kopiert die ganze Versionsgeschichte
- herunterladen von einem repository  

*Commit:*
- "Versionen"
- Änderungen, die zu einem bestimmten Zeitpunkt gemacht wurden. 

*Hashwert*
- Fingerabdruck von Commit, mit relevanten Informationen.

*Pull*
- Seite neu laden
- Die neuste Versionen mit den neusten Änderungen erhalten.

*Push*
- Änderungspaket wird ans Remote Repository geschickt.

*Merge*
- Zusammenfügen von verschiedenen branches, "Änderungen"

*Branch*
- Kopie des aktuellen Projektstands zum experimentieren
- verändert dann nicht die Hauptversion
- Original und Kopie im gleichen Repository

*Stage*
- Git erkennt automatisch, dass Dateien verändert wurden.
- Du fügst die Änderungen der Stage hinzu, damit sie beim nächsten Commit gespeichert werden können.
- Die Stage ist ein Zwischenbereich für Änderungen, die beim nächsten Commit gespeichert werden sollen.
